# JavaScript Practice Projects

This repository contains a collection of small JavaScript practice projects and exercises covering:

- basic JavaScript syntax
- functions and logic
- objects and arrays
- event handling
- shopping cart logic
- quiz apps
- expense tracking
- registration form examples

## Project folders

- `basic_syntax.js` — core JavaScript syntax exercises
- `cart_logic.js` — cart-related logic practice
- `dummy-userdata.js` — sample user data examples
- `event.js` — event handling examples
- `func.js` — function practice
- `funcs.js` — additional function examples
- `object.js` — object-based exercises
- `opps.js` — operator and logic practice
- `quiz_game.js` — simple quiz logic
- `expense-tracker/` — expense tracker app
- `mini_shopping_cart/` — mini shopping cart app
- `quiz-app/` — interactive quiz app
- `restration-form/` — registration form example
- `shopping-cart/` — shopping cart UI example

## Running the apps

Most of the front-end projects are static HTML/CSS/JS apps. To run them:

1. Open the folder in a browser.
2. Open the HTML file, such as `index.html`.
3. If needed, use a local server for better behavior.

Example:

```bash
cd /Users/reem/Documents/js_practice
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
